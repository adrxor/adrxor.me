# adrxor.me

Personal website and CMS for Adrian — ML/AI Engineer.

## Stack
- Astro + GitHub Pages for the public static site
- Cloudflare Worker for the API
- Cloudflare D1 for blog/research metadata
- Cloudflare R2 for research PDFs and podcast audio

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:4321`.

## Build

```bash
npm run build
```

## Important

The public site is static. The blog/research/podcast pages fetch published content from `https://api.adrxor.me` in the browser. The blog detail route is currently prepared for client-side loading; arbitrary `/blog/<slug>` paths are not pre-generated by Astro until a static fallback strategy is added.

The admin panel uses the Cloudflare Worker API and keeps a temporary Basic Auth token in `sessionStorage`.
